# KPC LIVE · Platinum Arena

## 依据与范围
- 用户提供《KPC LIVE 官网 PRD 说明文档.md》作为内容框架。
- 用户明确指定银色高端方向；文档第 12 节黑金是旧站记录，不作为当前指令。
- 借鉴 Rolls-Royce Project Nightingale 的大画幅、留白及段落节奏；不复制汽车视觉。
- 第一版为可运行的响应式中文品牌官网设计原型，包括首页内容和内容浏览交互。
- 线上站点返回 403，不能把生成的人物、场馆或封面描述成真实官方素材。
- 真实登录、报名、播放源、商店、社群和法律文本未由文档提供，不编造成功状态或正文。

## 设计系统
- 背景 #111315，首屏 #08090a；文本 #e4e5e5；次要文本 #a4a8ac。
- 边线 rgba(220,224,228,.22)，亮区 #c1c4c5，亮区文字 #1c2022。
- 英文字体 Cormorant Garamond / Georgia，中文 PingFang SC / Microsoft YaHei；正文 14–16px、行高 1.8。
- Hero 三行标题，左侧排版、右侧摄影；无标题前装饰标签。
- 原生可访问链接、按钮和文本；图像不包含页面文案或交互控件。
- 直角薄边按钮，细线箭头，开放式排版，避免卡片外套卡片。
- 桌面内容最大 1440px、边距约 6vw；移动端边距 24px。
- 细微显现和图像缩放，支持 prefers-reduced-motion。

## 页面节奏
首屏全幅深色摄影 → 人物肖像画廊 → 大场馆图片与赛事信息 → 视频与资讯 → 浅银品牌宣言 → 联系与页脚。
从原始框架调整视频资讯顺序以集中内容消费入口，全部首页模块仍保留。

## 素材
使用内置 Image Gen。hero-concept.png 是首屏设计基准；public/assets/platinum-chip.png 是从概念编辑提取的独立背景。
Hero 素材提示：右侧直立精密车削银色 KPC 筹码、石墨台呢、聚光、左侧留黑；去除所有页面文本，保留筹码物理雕刻 KPC。
生成主视觉为静态摄影；不将静态图伪称为视频。

## 生图限制与后续章节
首屏设计与独立主视觉成功生成。中段和尾段请求先出现连接错误，改为单次请求后返回 HTTP 401 / IP 未授权；因此没有可用的后续章节概念图。未使用付费 CLI 兜底。后续章节依据 PRD 与首屏设计系统实现，不能宣称已经过独立生图方案的逐像素验收。

- 银色品牌主视觉使用静态生成摄影，背景未伪造循环视频。
- 首页概念白名单中的标题、副文案、导航与 CTA 保留；移除无实际功能的轮播页码，改为赛事日历。
- 合作伙伴原标识未提供，当前仅展示可确认的 KPC 主品牌入口。
